# צילומי מסך של האפליקציות

שים כאן את צילומי המסך, תיקייה לכל אפליקציה, בשמות ממוספרים שמתחילים ב-1:

```
assets/screens/courierinfo/1.png
assets/screens/courierinfo/2.png
assets/screens/courierfinance/1.png
assets/screens/alertly/1.png
assets/screens/kdelivery/1.png
```

- אין צורך לשנות קוד. האתר מחפש לבד את הקבצים `1`, `2`, `3`... (בסיומת png, jpg או webp), עד הראשון שחסר.
- אם אין קבצים, לא מופיע כלום באתר, גם לא כותרת "צילומי מסך".
- איפה הם מופיעים: בכל כרטיס בדף הבית (עד 4 ראשונים, פס גלילה), ובדף המוצר של האפליקציה (עד 8, בתוך מסגרת טלפון).
- פורמט מומלץ: PNG, JPG או WebP, יחס טלפון (למשל 1080x2340), עד כ-150KB לכל תמונה.
- צילומים אמיתיים של האפליקציה בלבד.
